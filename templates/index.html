Machine Learning Inside

What's different?

CineStream combines two distinct ML paradigms for superior recommendations.

🔍
Unsupervised (Untracked)

K-Means Clustering

Movies are grouped purely by their genre fingerprint — no ratings needed. K-Means finds natural clusters like "Action + Thriller" or "Animation + Family" using the elbow method and silhouette scores to pick the optimal k.

K-MeansPCASilhouette
🎯
Supervised (Tracked)

Rating Prediction

Your ratings teach the model your taste. KNN Regressor and Random Forest predict the score you'd give every unseen movie. Evaluated with RMSE, MAE and R² — with and without the cluster feature to prove unsupervised helps.

KNNRandom ForestRMSER²
⚡
Together

Better Together

The cluster ID from K-Means becomes a feature in the supervised model. This bridge between unsupervised and supervised learning measurably improves prediction accuracy — a core concept in modern ML pipelines.

About CineStream

Video Production
Platform

CineStream isn't just a recommendation engine — it's a complete ML showcase. Built with Flask, Scikit-learn, and GSAP, it demonstrates how unsupervised and supervised learning can be combined into a real-world product pipeline.

  • ✓ One-hot genre encoding & feature engineering
  • ✓ K-Means clusters with PCA visualisation
  • ✓ KNN vs Random Forest with live metrics comparison
  • ✓ TMDB poster integration with graceful fallbacks
  • ✓ Fully responsive with GSAP animations
